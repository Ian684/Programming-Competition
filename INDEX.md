## Review checklist

For each solution, record the problem source, input/output assumptions,
algorithm, time complexity, space complexity, and at least one edge case.
Solutions are standalone scripts, so run them with redirected sample input:

```bash
python3 central_region_competition/Stack.py < sample.txt
```

Some solutions may require the original contest statement or judge-specific
input. Keep those assumptions in the corresponding note rather than changing
the solution silently.
